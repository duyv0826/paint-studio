# 今天就能跑完的最短标定路径（12 分钟，单段，n=1）

> 目的：把原型里「温柔 / 标准 / 严厉」三档的笔速门槛与断崖比例，从**设计取值**换成**有出处的数**。
> 口径必须写成 **n=1 预标定**，不能写成「实验验证」——样本量是 1，说清楚才站得住。

## 一、你要做的（12 分钟）

1. **双击** `标定\笔速标定采集页.html`（Chrome / Edge 打开）。
2. 页面上的**画布是 900×600 CSS 像素**，**开全屏或把窗口拉宽到能完整显示画布，之后不要再缩放窗口**。窗口一缩放，px/s 就不可比，这一趟白采。
3. 编号填 `S01`，时长填 `12`（分钟）。
4. 用**你平时画画的那支笔**（数位板就用数位板，别中途换鼠标），全程同一设备。
5. 点「开始」，然后**按真实自习状态画一张速写或临摹**——不要乱涂、不要为了数据好看刻意加速。
6. 中途**必须做这两件**：
   - **停手 2 次，每次 60–90 秒**（一次假装看手机，一次纯发呆）。停手本身就是数据。
   - **明显放慢 2 次**：找细节反复擦改、笔悬着犹豫不落。
7. 到点会自动导出 `标定_S01_日期_时间.json` 到浏览器下载目录。
8. 把这个 JSON 放进 `标定\导出\`（没有这个文件夹就新建）。

## 三、12 分钟能改什么、不能改什么（先说清楚，免得白等）

| 参数 | 这一趟能不能定 | 原因 |
|---|---|---|
| 笔速门槛（现在是 300 px/s） | **能** | 4800 个采样点足够算分位 |
| 断崖比例 `cliffRatio`（现 0.35 / 0.35 / 0.35 量级） | **能** | 掉落比例有连续分布 |
| 停笔阈值 `idleSec` | **不能** | 12 分钟只会有 2–3 个停笔段，p25/p75 是幻觉；这一项保持现有设计值，等真的凑到 6 个人再改 |
| `cliffDwellSec` / `cooldownSec` | **不改** | 这两个是交互手感参数，由屏幕刷新与提醒节奏决定，和笔速分布无关 |

## 四、这一趟最大的风险

**你自己的画法会决定结果。** 如果你是「慢工细活型」，标出来的笔速 p25 可能只有 80–100 px/s，那现在的 300 px/s 门槛会把你正常作画全判成「断崖」；反过来如果你是「飞快起稿型」，结果可能几乎不动。这个结论无论朝哪边，都是你要在答辩里讲的**真实发现**，不是失败——但如果结果和预期反着来，阈值是要改的，改完「标准档」的手感会和现在不一样。这一点我不粉饰。

## 五、之后怎么补到 n=6

同一页发 5 个同学，每人一段 20 分钟（按 `README_标定流程.md` 的原口径），全部丢进同一个 `标定\导出\`，重跑同一条命令即可。脚本按 `participant_id` 分人，混在一起也算得对。
