# 绘画自习室 · 桌面小窗 使用说明（v0.9 完全品）

一句话：**它不在你这里画画，它读你电脑上的落笔，把落笔切成一笔一笔的「笔触」，一边计时，一边让同桌上的人看得见你、能对你发问号。**

---

## 1. 三十秒上手

| 你要做的 | 怎么做 |
|---|---|
| 打开 | 双击 `打包\绘画自习室.exe`（不需要装 Python、不需要装任何东西） |
| 换昵称 / 换桌号 | 点标题「绘画自习室 · 302」，弹出小窗改昵称和桌号，保存即可（下次自动记住） |
| 开始自习 | 点「开始」，25 分钟番茄钟开始走 |
| 画画 | 打开你的绘画软件（PS / SAI / CSP / Krita / Painter…），照常画。小窗自己会记账 |
| 看状态 | 四格数字每 0.5 秒刷新；下面一行小字是笔速、峰值、节奏、短笔触占比 |
| 导出 | 点「导出数据」，生成 `导出\自习室_*.json` |
| 收起来 | 点标题右上的「—」变成 152×42 的小条；点「✕」退出 |

三种启动方式，任选：
- `打包\绘画自习室.exe` —— 单文件，双击即开（推荐给别人）
- `启动小窗.bat` —— 有 exe 就直接跑 exe，没有就用本机 Python 拉起脚本
- `python paint_studio_widget.py` —— 开发者方式，可加参数（见第 9 节）

## 2. 界面每一块是什么

```
┌─────────────────────────────────────────┐
│ 习  绘画自习室 · 302   云·联      —  ✕ │  ← 标题（点它＝设置）／联机状态
│  06:50   ● 在画                  [暂停] │  ← 番茄钟／实时状态／开始暂停
│  标准档 · 停笔会被提醒，6 秒后同桌补问号 │  ← 提示行（提醒、问号会占这里）
│ ┌──────┬──────┬──────┬──────┐          │
│ │ 笔触 │ 均笔触│ 撤回率│ 每分钟│         │  ← 四格
│ │ 128  │ 328  │  7%  │ 7.9  │          │
│ └──────┴──────┴──────┴──────┘          │
│  笔速 340 · 峰值 612 · 节奏 稳 · 短笔触 2%│  ← 笔触第二行
│  [温柔] [标准] [严厉]                    │  ← 档位（越右越紧）
│  同桌 ●阿岩 ●老周                  [?]  │  ← 真实在线同桌（点名字＝给他发问号）
│  [导出数据] [守护 开]        photoshop.exe│  ← 导出／守护开关／当前前台程序
└─────────────────────────────────────────┘
```

- **联机状态**：`云·联`＝公网已连上；`仅局域网`＝只有 Wi-Fi 内能看见；`离线`＝两条都没通。
- **同桌**：圆点是状态色——绿＝在画，灰＝停着/没开始，红＝被提醒了或在摸鱼。
- **右下角程序名**：只有它在你允许的绘画软件里，笔触才计入。看到 `—` 说明前台不是绘画软件。

## 3. 同桌：同一桌号，人在哪都能看见

两条通道**同时开**，谁先到算谁：

1. **公网（默认开）**：同一个桌号，两个人不在同一个 Wi‑Fi 也能互相看见。走公共 MQTT 服务器（TLS 加密），**三个依次试、哪个通用哪个、断久了自动换**：`broker.emqx.io` → `broker.hivemq.com` → `test.mosquitto.org`（都是 8883）。不需要账号、不需要服务器、不需要开端口。
   - **口令**：设置里可以填一个口令，两人必须一样。填了口令之后，房间主题变成 `sha256(桌号+口令)` 的前 16 位——**光猜到桌号进不来**，导出的 JSON 里也只写 `secured: true`，不写口令本身。
2. **局域网（默认开）**：同一 Wi‑Fi 下自动互相发现（组播 `239.255.60.60:47826`），零配置，断网也能用。

怎么用：
- 两个人各自打开小窗，**昵称不同、桌号相同**（比如都填 `302`），两秒内就会在「同桌」一行看见对方。
- **点对方的名字**＝给他发一个问号；点右边的「？」＝发给第一个没在画的人。
- 收到问号：窗口红框闪一下、提示行写「XX 发来一个问号」、响一声。
- **自动补问号**：你被系统提醒（停笔超阈值）之后 6 秒如果还没动笔，房里其他正在画的人的小窗会自动替你发一个问号——这就是录音里讲的「系统先提醒，然后大家发问号施压」的第二段。
- 关掉同桌（设置里「这一轮有同桌」取消勾选）＝独桌条件，只留系统提醒，用于做对照实验。

**注意**：公共 broker 是公共设施——房间里流动的只有昵称、状态、笔数、问号；不传画面、不传坐标、不传文件名。如果研究要求更严格的数据隔离，改用局域网通道（`--no-cloud`）。

## 4. 它怎么判断「你在认真画」

被监测的东西只有三样：**全局指针位置、左键按下/抬起、Ctrl+Z**（数位板在 Windows 上就等价于鼠标）。采样标称 30 Hz，实测约 21 Hz（导出里 `source.measured_hz` 给真实值，标称值仅作对照）。
落笔/抬笔的**时刻与坐标**由低层鼠标钩子（`WH_MOUSE_LL`）在事件发生那一刻取，只记录、不拦截；`--no-hook` 可退回纯轮询（此时起笔点会晚一个采样间隔，约 20–25 px，`source.mouse_hook` 会记 false）。

判定顺序：
1. 前台进程不在白名单 → 状态「不在绘画软件」，不计入；不开守护。
2. 超过阈值没落笔 → 「停 Xs」→ 提醒（窗口变色＋提示行＋可选提示音）。
3. 笔速断崖：峰值曾 ≥300 px/s，之后 3 秒内掉到峰值的 35% 以下并持续若干秒 → 算「手停了但笔还压着」，也提醒。
4. 提醒后进入 `pending`，直到你重新落笔；这期间同桌的问号会被记进压力记录。

三档阈值（可在界面切换，同一场实验里不要中途换）：

| 档 | 停笔阈值 | 断崖比例 | 断崖持续 | 提醒冷却 |
|---|---|---|---|---|
| 温柔 | 60s | 28% | 4s | 45s |
| 标准 | 20s | 35% | 3s | 30s |
| 严厉 | 10s | 50% | 2s | 15s |

## 5. 笔触：一笔一记，这是核心

你把笔按下去到抬起来，算**一笔**。每一笔记这些：

| 字段 | 含义 |
|---|---|
| `i` | 第几笔（从 1 开始） |
| `t0` / `t1` / `dur` | 起止时刻（绝对 epoch 秒，可换算成钟点）／这一笔持续多久 |
| `path` | 笔内累计轨迹长度（px，不是直线距离——来回涂也算） |
| `avg_v` / `peak` | 笔内平均速度／峰值速度（px/s） |
| `pauses` | 笔内停顿次数（压着笔不动 ≥0.25s 计一次） |
| `straight` | 直线度 0–1（位移/轨迹，1＝很直，低＝来回描） |
| `x0,y0,x1,y1` | 起笔点、终点（屏幕坐标） |
| `undo` | 这一笔有没有被撤回（Ctrl+Z 后 3 秒内归给「最近画完的那一笔」） |
| `at` | 落笔的钟点时间 |

聚合出来的 `brush`：

| 字段 | 含义 | 为什么有用 |
|---|---|---|
| `stroke_count` | 总笔数 | 「我画了多少笔」 |
| `avg_len_px` / `median_len_px` / `max_len_px` | 平均/中位/最长笔长 | 长笔＝铺色，短笔＝抠细节 |
| `median_dur_s` | 单笔中位时长 | 一笔磨多久 |
| `short_ratio` | 短笔触（<20 px）占比 | 高＝在抠细节或反复试笔 |
| `undo_strokes` / `undo_rate` | 被撤回的笔数／撤回率 | 「撤回步数」的笔触口径 |
| `median_gap_s` | 相邻两笔间隔中位数 | 画的节奏 |
| `rhythm_mad_ratio` | 笔间隔的 MAD/中位数（乘 1.4826 对齐标准差口径） | **做因变量用这个**：一次起身停顿不会把它拉爆 |
| `gap_p90_s` | 笔间隔 90 分位 | 「最慢的那一成停顿有多长」 |
| `long_gaps` | 超过 2 倍中位间隔的间隔个数 | 「中途起身了几次」，可直接进结果表 |
| `rhythm_cv` | 笔间隔的变异系数（原始，仅留作对照） | 对单个长间隔极敏感：一次 30s 停顿就能把整场判成「散」，不要拿它做假设检验 |
| `pauses_total` | 笔内停顿总数 | 犹豫/找参考的痕迹 |
| `straight_median` | 直线度中位 | 起草 vs 收线 |

**一句话读懂**：`笔触` 是手的动作留下的形状，不是画面内容，也不是压感。画面好不好它不知道；它知道你有没有在动、动得像不像在画。

## 6. 数据导出

点「导出数据」，落在 `导出\自习室_<档位>_<with_peers|system_only>_<时间戳>.json`。结构（`schema_version: 3`）：

```
{
  "app": "绘画自习室 · 桌面悬浮小窗 v0.9（笔触 + 自习桌）",
  "exported_at": "...",
  "source":   { input, foreground_filter, draw_apps, sample_hz, measured_hz, mouse_hook,
                dpi_scale, dpi_monitors, dpi_refresh_count, dpi_change_count, hook_scale_manual,
                hook_skew_max_px, hook_scale_warn },
  "session":  { started_at, ended_at, active_sec, condition, social_condition, planned_min },
  "desk":     { stroke_count, undo_count, path_px, pen_down_sec,
                avg_speed_px_s, peak_speed_px_s, current_speed_px_s, strokes_per_min,
                brush: {...}, stroke_samples: [ 最近 300 笔原始记录 ] },
  "guard":    { enabled, level, thresholds, reminder_count,
                reminders: [ {signal, at, delay_ms, exe} ] },
                # signal=idle|cliff；delay_ms＝提醒之后到重新落笔的毫秒数（没回笔则为 null）
                # exe＝触发时的前台程序，用来核对「是不是在绘画软件里被提醒的」
  "room":     { code, me, peer_id, lan, cloud, peers_enabled, demo_peers,
                peer_states: [{id,name,state,reminded}], qmark_sent, qmark_received,
                pressure: [ {at, from, via, auto, after_reminder_ms, reaction_ms} ] },
  "pomodoro": { rounds_completed, focus_sec },   # focus_sec＝本次真正在番茄钟里的秒数（按真实时间差累加，暂停不计）
  "data_valid": true/false,
  "limits": [ 五条已知限制，随数据一起走 ]
}
```

研究用法：
- `source.mouse_hook`＝本次是否用钩子取落笔点；`dpi_monitors`＝每块屏的物理/虚拟矩形与换算系数；`dpi_refresh_count`＝换算表重读次数（含例行重读，不等于出过问题）；`dpi_change_count`＝换算表内容真的变了次数（>0 说明中途插拔过显示器或改过缩放，程序已自动纠正）；`hook_skew_max_px`＝钩子坐标与当拍光标的最大偏差（正常 ≤25 px）；`hook_scale_warn`＝偏差超 120 px 被判定为尺子错位（该场请剔除或加 `--hook-scale` 重跑）。
- **RQ「笔触能不能代理专注」**：`brush.short_ratio + median_gap_s + rhythm_cv + pauses_total` 四个数，配 `reminder_count`。
- **RQ「问号压力有没有用」**：`pressure[].after_reminder_ms`（提醒后多久收到问号）、`reaction_ms`（收到问号后多久重新落笔）。
- **条件对比**：`social_condition` 区分「有同桌 / 独桌」，文件名也带。

## 7. 已知限制（不粉饰）

1. **没有压感/倾角**。读笔压要订阅数位板 HID 原始报文（Raw Input），各品牌报文不同，且没有平板可测。所以「笔触」是几何口径，不是力度口径。
2. **撤销靠 Ctrl+Z**。如果你的软件用 `Ctrl+Shift+Z` 或面板按钮撤销，会漏记（可自己改一行 `key_down(0x5A)` 判断）。
3. **落笔＝左键按下**。绝大多数数位板落笔等价左键；个别软件/驱动改了映射，开场前空手画两笔确认 `笔触` 会涨。
4. **只认前台白名单里的软件**（PS、SAI、CSP、Krita、Painter 等）。冷门软件加进 `DRAW_EXES`，或者用 `--anywhere` 全算。
5. **公网通道依赖第三方公共 broker**（emqx / hivemq / mosquitto 三个轮流试）。它们免费、无 SLA；万一三个都连不上（比如机房整体封 8883），只剩局域网通道，状态会显示「仅局域网」。
6. **口令是弱保护**。它把主题变成哈希，猜桌号不再够；但 broker 上任何人只要拿到这个哈希就能订阅。房间里只放昵称、状态、笔数、问号，别往里塞任何敏感内容——这是设计边界，不是「加密聊天」。
7. 只支持 Windows。macOS 需要另写一套（`CGEventTap`）。
8. **钩子坐标要换算，且每块屏各算一遍**。进程没声明 DPI 感知，`GetCursorPos` 报的是虚拟化坐标，`WH_MOUSE_LL` 报的是物理像素——本机 4K 那屏是 2 倍（0.5），2560×1440 那屏是 1.5 倍（0.667）。程序按「每块屏的虚拟矩形 ÷ 物理矩形」各算一个系数，两块屏都实测过：钩子报的坐标换算后与 `GetCursorPos` **完全一致**（零点位，delta 0,0）。换算表写进 `source.dpi_monitors`，主屏系数写 `dpi_scale`。
   - 换算表不只启动时读：距上次读满 10 秒、或按下点落在所有已知屏之外（插了新屏）时**自动重读**（重读次数记 `dpi_refresh_count`）。所以中途改缩放/插拔显示器不用重开小窗，最迟 10 秒（或下一次落笔）就纠正。
   - 竖屏/旋转：靠两块矩形各自的宽高独立算 x/y 系数，旋转屏按「旋转后的像素」参与计算（自检里有竖屏 1440×2560@150% 的用例）。
   - 过期表的兜底已用**真实钩子事件**验过（`测试\stale_maps_test.py`）：手里拿着「错 2 倍」的旧表时，按下点 600 对当拍光标 300 → 退回 300 并记 `warn=true`、`skew_max=300`；重读换算表后再点一次 → 回到 700 精确、`skew_max=0`。这条不改任何显示设置，可随时复跑。
   - 旋转屏**真机**验过（`测试\rotate_probe.py`，临时把副屏转 90°、30 秒看门狗自动转回）：旋转后 2560×1440 → 虚拟 960×1707、物理 1440×2560，两轴系数同为 0.667；屏上点击光标 3040/1093 对钩子 3040/1094（偏差 1 px）；`dpi_change_count` 旋转时 0→1、转回时 →2。
   - `--hook-scale` 也验过（`测试\hook_scale_test.py`）：钉对 0.5 时起笔精确（skew 0）；钉错 1.0 时钩子报 1400 对光标 700 → 被尺子校验拦住、退回 700 并 warn。
   - 兜底 1：`--hook-scale 0.5` 可手动钉死一个统一系数（异形缩放/远程桌面等读不出矩形的场合）。手动模式下**完全不查表、也不重读**，因此不会被自动换算顶掉。
   - 兜底 2：运行时校验——按下点与当拍光标差 >120 px（正常只差一个采样间隔 ≈25 px）就判定尺子错位，**退回当拍坐标**并在导出里记 `hook_scale_warn: true`，最大值记 `hook_skew_max_px`。
   - 兜底 3：`--no-hook` 退回纯轮询（全虚拟化坐标，一致但起笔点晚一个采样间隔）。

## 8. 一场实验怎么跑（建议流程）

1. 开场前 5 分钟：两个人各自打开小窗 → 设置里填昵称、同一个桌号 → 确认对方出现在「同桌」一行 → 联机状态显示「云·联」。
2. 让被试打开自己的绘画软件，随便画两笔，确认四格里「笔触」在涨、右下角显示的是他的软件名。
3. 选同一档位（建议「标准」），点「开始」。
4. 25 分钟里你不说话、不介入；系统提醒和问号都是自动发生的（这是设计的一部分）。
5. 结束：点「导出数据」，把 JSON 收走；文件名已带档位与条件，不用另记。
6. 收两份（被试 + 同桌）就能对齐「谁发的问号、谁收的、多久后动笔」。

## 9. 参数（开发者用）

```
python paint_studio_widget.py                      # 默认 房间 302 / 昵称「我」
python paint_studio_widget.py --name 小林 --room 302 --pass x7k
python paint_studio_widget.py --anywhere            # 不限绘画软件
python paint_studio_widget.py --no-lan              # 只走公网（异地测试）
python paint_studio_widget.py --no-cloud            # 只走局域网（断网/严格隔离）
python paint_studio_widget.py --autostart            # 启动即开番茄钟（自动化测试必备：守护只在计时中工作）
python paint_studio_widget.py --solo                 # 独桌条件：会强制断掉局域网与公网两条通道，导出落 system_only
python paint_studio_widget.py --solo --covert         # 独桌条件＋盲化：座位行仍显示「同桌（离线）」，不出现「独桌」二字，徽标固定显示「仅局域网」
python paint_studio_widget.py --covert-peers "阿岩,老周"  # 盲化占位用的同桌名（填被试那位同桌的真实昵称更像真的）
python paint_studio_widget.py --pid 01 --session 2 --piece B --order AB1   # 实验标识：写进导出 session 块，文件名带 P01_S2_
python paint_studio_widget.py --no-hook              # 关掉鼠标钩子，退回纯轮询（对照实验/钩子装不上时用）
python paint_studio_widget.py --hook-scale 0.5        # 手动钉死钩子坐标换算系数（读不出屏幕矩形的场合）
python paint_studio_widget.py --theme paper           # 旧文创配色（奶油纸底＋楷体）；默认是正式版配色，可整窗回退
python paint_studio_widget.py --selftest             # 逻辑自检（36 项，报告写到 自检结果.txt）
python paint_studio_widget.py --net-test            # 局域网通道自检
python paint_studio_widget.py --cloud-test 8 --name A --room t1   # 公网通道自检
python paint_studio_widget.py --probe 5             # 只读 5 秒全局指针
python paint_studio_widget.py --export-test --export-after 3      # 导出一次
python paint_studio_widget.py --snapshot out.png --snap-delay 4    # 自己截自己
```

配置文件 `自习室配置.json`（和 exe / 脚本同目录）：`{"name": "...", "room": "...", "peers_on": true}`。

## 10. 文件清单


## v0.9.1：迷你态关不掉（2026-11-14 修）

现象：点标题条的「—」收成小条后，找不到任何能关掉窗口的地方。

成因（实测，不是猜）：窗口用 `overrideredirect(True)`，没有系统标题栏、没有任务栏按钮，Alt+F4 不生效；唯一出口是标题条上的 ✕ 与 `Esc`。旧版迷你态把窗口缩到 152×42，但标题条的布局宽度仍是 336——实测 `✕` 落在 x=293、`—` 落在 x=313，都在 152 px 窗口右侧之外，等于把唯一的出口推出了可视区；迷你行本身又没有展开/退出控件。

修法：迷你态不再保留标题条，改为一条自足的小条（186×34）：`时间 / 状态 / ⤢ 展开 / ✕ 退出`，全部落在窗口内（实测展开键 x=141、关闭键 x=161）；另加三个冗余出口——点时间可展开、整窗右键菜单（展开 / 导出 / 退出）、`Esc` 退出。自检仍 36/36。
