## 绘画自习室 v0.9.1 · Windows 免安装版

双击即用，**不需要装 Python、不需要装任何运行时**。单文件 pyinstaller 打包，Windows 10/11 x64。

### 这一版能做的

- **笔触记账**：读全局指针，把落笔切成一笔一笔 —— 每笔的时长、累计轨迹长度、平均/峰值速度、笔内停顿、直线度；Ctrl+Z 撤回归给最近画完那一笔，算撤回率。
- **四格实时面板**：笔触 / 均笔触 / 撤回率 / 每分钟，下面再一行笔速 · 峰值 · 节奏 · 短笔触占比。
- **番茄钟 + 守护**：温柔 / 标准 / 严厉三档，停笔超时提醒、笔速断崖提醒。
- **自习桌**：同一桌号的两个人两条通道同时开 —— 局域网组播零配置，或公共 MQTT（三个 broker 依次试）。点对方名字发一个问号。
- **只在绘画软件里计数**：前台白名单含 PS / SAI / CSP / Krita / Painter 等 24 个进程名。
- **导出 JSON**（schema_version 3）：五块数据，连「五条已知限制」一起写进文件，脱库也不会被误读。
