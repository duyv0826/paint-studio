# 设计文档

课程《交互设计概论》的三份交付物，讲同一个东西：这个工具为什么长这样、它验证了什么、最后剩下什么没验证。

| 文件 | 是什么 | 与代码的关系 |
|---|---|---|
| `研究报告_同桌在场对绘画练习专注度的影响.pdf`（另有 `.docx`） | 研究论文：文献综述 → 研究问题与假设 → 方法 → 结果 → 讨论 → 局限。核心论点是「笔触能不能代理专注」「同伴在场是促进还是惰化」 | 报告里的实验，就是用本仓库 `src/paint_studio_widget.py` 跑的；导出的 JSON 字段在论文里逐条对应 |
| `设计手册_A4.pdf`（另有 `.docx`） | 设计手册：问题与用户、竞品覆盖对比、三条访谈原话如何变成设计决定、界面逐块说明 | 界面截图为 v0.9 实机；参数口径与 `docs/使用说明.md` 一致 |
| `汇报演示.pdf`（另有 `.pptx`） | 15 页答辩稿 | — |

## 一句话读法

如果你只有五分钟：先看设计手册第 2 节（三条访谈原话 → 三个设计决定），再看研究报告第 6.1 节（笔触能代理什么、不能代理什么）。后者是这个项目最诚实的一节，它明确写了哪些结论现有数据撑不住。
